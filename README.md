# Customer Churn Prediction & Retention Analytics Platform

## Overview
Built a machine learning-powered analytics platform that predicts customer churn and generates retention insights using behavioral and transactional data.

## Tech Stack
- Python
- SQL
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Key Features
- Customer churn prediction
- Risk scoring
- Customer segmentation
- Retention analytics
- Automated data pipelines
- Model evaluation dashboards
